# ТЕХНОПРОГРЕСС

Многостраничный статический сайт ООО «ТЕХНОПРОГРЕСС» для продажи кабельно-проводниковой и электротехнической продукции.

## Страницы

- `index.html` - главная страница
- `catalog.html` - каталог с фильтрами
- `product.html?slug=vvgng-ls` - динамическая страница характеристик товара
- `cable.html` - SEO-раздел кабельно-проводниковой продукции
- `electrical.html` - SEO-раздел электротехники
- `solutions.html` - отраслевые решения
- `supply.html` - поставка под проектную спецификацию
- `guide.html` - справочник
- `contacts.html` - контакты и реквизиты
- `privacy.html` - политика конфиденциальности

## Заявки

В каждой форме есть выбор канала: `Email` или `Telegram-бот`.
Email работает сразу и открывает подготовленное письмо на `Head-tp@yandex.ru`.
Для подключения Telegram нужно указать webhook в `TELEGRAM_WEBHOOK_URL` внутри `app.js`.
Если бот будет открываться отдельной ссылкой, ее можно поставить в `TELEGRAM_BOT_URL`.
